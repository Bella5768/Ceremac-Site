# Images du Carrousel Hero

Placez vos images ici avec les noms suivants :

- **1.jpg** - Première image du carrousel (Recherche Océanographique)
- **2.jpg** - Deuxième image du carrousel (Laboratoires)
- **3.jpg** - Troisième image du carrousel (Formation)

## Spécifications recommandées :
- Format : JPG ou PNG
- Dimensions : 1920x600 pixels (ratio 16:5)
- Taille : < 500 KB pour des performances optimales
- Qualité : 80-90%

Les images doivent être liées au CEREMAC et à la recherche marine.
